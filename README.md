# Contact Book (File-Based)

## Project Description
The Contact Book is a simple Python command-line application that allows users to manage their contacts. It stores contact details such as name, phone number, and email address in a JSON file.

## Features
- Add new contacts
- View all saved contacts
- Search contacts by name
- Update existing contact details
- Delete contacts
- Store contact information in a JSON file
- Display contacts in a clean and readable format
- Handle invalid menu choices

## Technologies Used
- Python 3
- JSON module
- OS module

## How to Run
1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python contact_book.py
```

## How to Use
1. Run the program.
2. Select an option from the menu.
3. Enter the required contact details.
4. Search, update, or delete contacts using the available options.
5. Select option 6 to exit the application.

## Project Structure
- `contact_book.py` - Main Python source code
- `contacts.json` - Stores contact details and is created automatically
- `README.md` - Project documentation

## Data Storage
Contact information is saved in `contacts.json`, so the contacts remain available when the application is restarted.
